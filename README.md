# Anki

Консольная игра для заучивания слов. Колода читается из файла или по ссылке, ответы проверяются в терминале, после выхода словарь сохраняется обратно.

## Установка

Нужен Python 3.9 или новее.

```bash
python3 -m venv venv
source venv/bin/activate
pip install -e ".[dev]"
```

Команда `pip install -e ".[dev]"` ставит игру и инструменты разработки: pytest, mypy, ruff и black.

## Запуск

По умолчанию игра ищет `./words.txt` в текущей папке.

```bash
anki --source src/anki/words.txt
```

Свой файл или ссылка на JSON:

```bash
anki --source ./words.txt
anki --source ./words.json
anki --source https://code.s3.yandex.net/fullstack_developer/python-words
```

В текстовом файле каждая пара на своей строке, без пробела после запятой:

```text
яблоко,apple
кот,cat
```

TSV использует табуляцию: `яблоко	apple`. JSON — объект `{"яблоко": "apple"}`. Ссылка должна отдавать такой же JSON. Подходят адреса, которые начинаются с `http` или `https`.

## Меню

Пункты собираются заново на каждом шаге. Если в колоде нет слов, остаются только добавление слов и выход.

- Начать игру
- Добавить слова
- Тренировка до первой ошибки
- Тренировка на время
- Найти перевод
- Показать все слова
- Выход

В игре и при добавлении слов ввод `СТОП` завершает текущий режим. В тренировке на время программа сначала спрашивает лимит в секундах.

## Проверка

```bash
pytest
mypy --check-untyped-defs src/anki
ruff check src tests
black --check src tests
```
